# Titanic Survival Prediction
A Machine Learning project that predicts whether a Titanic passenger.
Would survive based on passenger information

## Feature
- Data preprocessing
- Missing Value handaling
- Label encoder
- Train-test-split
- Machine Learning model trainging
- Model evaluation
- Usr input base prediction

## Technology Used
- python
- pandas
- scikit-learn
- joblib

## How to Run
Install dependencies:
pip install -r requirements.txt
Train the model:
python train.py
Run Prediction:
python predict.py

## Prediction
The Program takes passenger information as input and predict:
- Passenger will Survive
- Passenger will not Survive

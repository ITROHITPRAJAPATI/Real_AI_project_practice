# K-Means Customer Segmentation

## Project Overview
This project uses the K-Means Clustering algorithm to group customers based on their Age and Salary.

## Features
- Customer Segmentation
- K-Means Clustering
- CSV Dataset
- Model Save using Joblib
- Load Saved Model
- Interactive Prediction

## Technologies Used
- Python
- Pandas
- Scikit-learn
- Joblib

## Project Structure

kmeans-customer-segmentation/
│── data/
│   └── customer.csv
│── models/
│   └── kmeans_model.pkl
│── train.py
│── predict.py
│── README.md

## How to Run

Train Model

```bash
python train.py
```

Predict

```bash
python predict.py
```

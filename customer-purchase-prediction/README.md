# Customer Purchase Prediction

## About
This project predict wether a customer will purchase a product based on Age and Salary

## Technology
- python 
- pandas 
- scikit-learn
- joblib

## Machine Learnig
- K-nearest Neighbors (KNN)
- StandardScaler

## How to Run
Install dependencies:
pip install -r requirement.txt
Train the model:
python train.py
Run Predictgion:
python predict.py

## Output

- Customer will Purchase.
- Customer will not Purchase.

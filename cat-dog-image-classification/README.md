# Cat vs Dog Image Classification

## 📌 Project Overview

This project uses a Convolutional Neural Network (CNN) to classify images into two classes:

- Cat 🐱
- Dog 🐶

## 🛠️ Technologies Used

- Python
- TensorFlow
- Keras
- OpenCV
- NumPy
- Scikit-learn

## 🧠 Model

The project uses a CNN with:

- Conv2D
- Batch Normalization
- MaxPooling
- Dropout
- Data Augmentation
- Sigmoid output layer

## 📂 Project Structure

cat-dog-image-classification/

├── data/

├── models/

└── src/

    ├── data_loader.py

    ├── model.py

    ├── train.py

    ├── evaluate.py

    └── predict.py

## 🚀 How to Run

Install dependencies:

pip install -r requirements.txt

Train the model:

python src/train.py

Evaluate the model:

python src/evaluate.py

Make a prediction:

python src/predict.py

## 📊 Evaluation

The model was evaluated using:

- Accuracy
- Confusion Matrix
- Classification Report

## 🎯 Learning Objective

The main purpose of this project is to understand the complete CNN image classification workflow from data loading to prediction.

# Customer Sentiment Analysis

## Project Overview

This is a Machine Learning project that predicts whether a customer review is positive or negative.

## Objective

The main objective of this project is to automatically analyze customer reviews and classify them into positive or negative sentiment.

## Technologies Used

- Python
- Pandas
- Scikit-learn
- TF-IDF Vectorizer
- Logistic Regression
- Joblib

## Machine Learning Workflow

1. Load the review dataset
2. Separate text and sentiment
3. Convert text into numerical features using TF-IDF
4. Split data into training and testing sets
5. Train Logistic Regression model
6. Evaluate model accuracy
7. Save the trained model
8. Load the model for prediction
9. Predict sentiment of a new customer review

## Example

Input:

I love this product

Output:

Positive

Input:

I hate this product

Output:

Negative
